领取规则（按套餐区分）

  • 免费 Free 账号：领取 Sand 需要自行手动绑定信用卡。点该账号那一行的「网页领取」，会用它的登录态打开浏览器直接到领取页，你在浏览器里完成绑卡即可。
  • Pro / Pro+ / Ultra 账号：套餐自带 Sand 资格（Cursor 资格接口返回「付费套餐自动授予」），所以刚导入、一验证就显示「已开通 · 套餐自带」——这不是领取动作，验证是只读的。「领取」对这类号只是再确认一次，会提示「本来就已开通」。
  • Team 账号：走团队通道，「领取」会自动带 teamId 申请开通。

常用操作

  • 导入账号：粘贴 access_token / ws token / 邮箱----token（每行一个），或「导入文件」选 cursor_accounts_*.json。导入后自动验证：识别邮箱、套餐、订阅剩余时间、三池用量。账号与状态都会自动保存，下次打开无需重导。
  • 验证账号：只做检查，不领取（不会碰任何领取接口）。判定 token 是否有效（过期 / 被服务端拒绝会标「失效」），读取 Sand 资格状态、套餐、订阅剩余、三池用量。「Sand 状态」列的「已开通」来自 Cursor 的资格接口，下面小字会写「套餐自带」或「本次领取」。
  • 批量领取：给账号领 Sand（Grok Bot）资格，已开通的直接跳过；可设「并发」数并行。勾选部分账号则只处理勾选的，不勾则处理全部。
  • 删除选中：批量删除勾选的账号；「清空」删全部。
  • 探测 Refresh / 刷新登录票：从本机 Cursor 或号池整行记录 refresh_token；再用它向官方 OAuth 换新的登录票。
  • 显示 Token：点「账号列表」标题右侧的按钮，或某一行邮箱下方的「显示 Token」（旁边是探测票 / 刷登录票 / 网页领取 / 复制）。会分别展示 Worksession（user_id::jwt）和 Refresh，可单独复制。默认关闭。
  • 进控制台：用该账号登录态打开隔离浏览器到 Cursor 控制台（dashboard/spending），可直接看用量 / 账单 / 设置。每个账号一个独立浏览器 profile，不影响你日常浏览器的登录。
  • 查看设备：用该号已有的登录票（token）直接调官方接口，不必每次浏览器登录。对应 dashboard Settings → Active Sessions；可勾选后踢掉所选，也可单台踢下线（与官网 Revoke 相同，成功后应立刻从列表消失）。若被网站人机校验拦截，点一次「打开 / 显示浏览器」即可：每个账号只开一扇隔离窗口，之后检测和踢下线都复用它，不会每 30 秒再开新窗口。请保持 cursor.com 标签不要关。接口不提供电脑名或 IP；若该号正在本机 Cursor 登录，一条客户端会标本机，多条则标可能是本机。
  • 本机设备保护：账号列表每行只放「本机保护」入口，点开会从右侧抽出抽屉；保护运行中也是打开抽屉，停止保护在抽屉里。开启前勾选要保留的设备，可用「全选保留 / 全不选 / 只留本机」，再点立即删除未勾选马上踢掉其余设备；也可设置检测间隔（秒，默认 30）后启动持续保护。抽屉里的「检测登录时间」会再弹一层设间隔（默认 120 秒）：把设备创建时间与本机现在比对，落在间隔内的标刚登录，并清空原勾选、只勾这些刚登录设备。可同时保护多个账号：表格勾选后点「批量保护」，每个号自动保留当前在线设备（有上次勾选则沿用），之后新登录会被踢；「停止选中保护」停勾选的号。顶部「保护中 N 个账号」可打开抽屉，多号时抽屉里可切换。点遮罩或「关闭」只收起抽屉，不会停止保护；关掉后可继续导入 / 验证 / 进控制台。保留名单不能为空；踢掉本工具自己用的那张登录票后，保护最多约 10 分钟失效并自动停止。重启本工具后需要重新点「本机保护」或再批量开启（会回填上次的勾选与间隔）。
  • 云端 Agent：在顶部「云端agent管理」页。与登录票账号列表独立。把 Cursor Dashboard → API Keys 里创建的用户密钥（crsr_...）粘贴进来，按密钥列出该账号下全部 Cloud Agent（含已归档）。列表每行可单独删除；「一键清理」会永久删除这把密钥下的全部 Agent，不可恢复，删除前会弹出数量确认。密钥只存本机、不上传；列表不显示完整密钥，输入框会记住上次粘贴的内容。

额度怎么看

  • Bot 周用量：Sand（Grok Bot）专属额度，每周重置；来自 GetSandUsageStatus。
  • Auto 月用量 / 高级(API) 月用量：账单月内两个独立的池子，来自 usage-summary。三者互不相加；Cursor 自己的「总用量」是两池加权混合值，这里不再当用量显示。
  • 按量付费：若出现「已扣 $x」，说明该号已开 on-demand 并产生了真实账单。

登录设备

对应 Settings → Active Sessions。勾选后可「踢掉所选」，成功后应立刻从列表消失。接口不提供电脑名或 IP。

检测登录时间

把每台设备的创建时间与本机现在比对。落在间隔内的会标「刚登录」，并清空原勾选、只勾这些刚登录设备（接口没有电脑名）。
