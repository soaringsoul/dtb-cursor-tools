领取规则（按套餐区分）

  • 免费 Free 账号：领取 Sand 需要自行手动绑定信用卡。点该账号那一行的「网页领取」，会用它的登录态打开浏览器直接到领取页，你在浏览器里完成绑卡即可。
  • Pro / Pro+ / Ultra 账号：套餐自带 Sand 资格（Cursor 资格接口返回「付费套餐自动授予」），所以刚导入、一验证就显示「已开通 · 套餐自带」——这不是领取动作，验证是只读的。「领取」对这类号只是再确认一次，会提示「本来就已开通」。
  • Team 账号：走团队通道，「领取」会自动带 teamId 申请开通。

常用操作

  • 导入账号：粘贴 access_token / ws token / 邮箱----token（每行一个），或「导入文件」选 cursor_accounts_*.json。导入后自动验证：识别邮箱、套餐、订阅剩余时间、三池用量。账号与状态都会自动保存，下次打开无需重导。
  • 验证账号：只做检查，不领取（不会碰任何领取接口）。判定 token 是否有效（过期 / 被服务端拒绝会标「失效」），读取 Sand 资格状态、套餐、订阅剩余、三池用量。「Sand 状态」列的「已开通」来自 Cursor 的资格接口，下面小字会写「套餐自带」或「本次领取」。
  • 批量领取：给账号领 Sand（Grok Bot）资格，已开通的直接跳过；可设「并发」数并行。勾选部分账号则只处理勾选的，不勾则处理全部。
  • 删除选中：批量删除勾选的账号；「清空」删全部。
  • 导出全部：txt 先按套餐分大类（Ultra → Pro+ → Pro → 团队 → Free），大类里再分「未用 Bot 额度 / 已用 Bot 额度 / 到期不续」，失效与未验证单独放最后；文件头给出各套餐数量，每段头部注明分类依据与每个号的到期 / 剩余 / Sand / 三池用量，段内按订阅剩余时间从短到长。账号行保持 邮箱----user_id::token，可原样再导入。
  • 进控制台：用该账号登录态打开隔离浏览器到 Cursor 控制台（dashboard/spending），可直接看用量 / 账单 / 设置。每个账号一个独立浏览器 profile，不影响你日常浏览器的登录。
  • 查看设备：用该号已有的登录票（token）直接调官方接口，不必每次浏览器登录。对应 dashboard Settings → Active Sessions；每台都可踢下线（与官网 Revoke 相同，成功后应立刻从列表消失）。若被网站人机校验拦截，点一次「打开 / 显示浏览器」即可：每个账号只开一扇隔离窗口，之后检测和踢下线都复用它，不会每 30 秒再开新窗口。请保持 cursor.com 标签不要关。接口不提供电脑名或 IP；若该号正在本机 Cursor 登录，一条客户端会标本机，多条则标可能是本机。
  • 本机设备保护：点某行「本机保护」会在账号列表下方打开面板（不挡窗口，导入 / 验证 / 进控制台照常用）。开启前勾选要保留的设备并设置检测间隔（分钟）。若该号正在本机 Cursor 登录：云端只有一条客户端会话会标本机，多条则都标可能是本机（接口不区分电脑）。之后按间隔检测并自动下线未保留设备。点「收起」只藏面板，不会停止保护；点顶部「保护中」标签可再打开。保留名单不能为空；踢掉本工具自己用的那张登录票后，保护最多约 10 分钟失效并自动停止。重启本工具后需要重新点「本机保护」（会回填上次的勾选与间隔）。
  • 本机 Cursor 补丁：给本机 Cursor 打 / 回退 Sand 客户端模式补丁，规则与 cursor-account-manager 插件完全同一套（兼容 3.18.9 / 3.18.25 / 3.19.13）。面板逐条列出请求头、本地回路、子代理生命周期等规则状态；点「打补丁」会关闭 Cursor、按插件逻辑写入并校验、重签名后重启。打完后点「验证生效」可读 Cursor 的 agent-host 日志。
  • 「显示成功其实没成功」的常见原因：① 本机装了多个 Cursor，补丁打在 A、平时开的是 B（面板会标出正在运行的 Cursor 路径，用「设置路径」指到你实际用的那份）；② Cursor 自动更新把文件换回去了（关自动更新，重新打）；③ 补丁没问题但本机登录号没有 Sand 资格 / 票已失效（报告最后一步会告诉你）。

额度怎么看

  • Bot 周用量：Sand（Grok Bot）专属额度，每周重置；来自 GetSandUsageStatus。
  • Auto 月用量 / 高级(API) 月用量：账单月内两个独立的池子，来自 usage-summary。三者互不相加；Cursor 自己的「总用量」是两池加权混合值，这里不再当用量显示。
  • 按量付费：若出现「已扣 $x」，说明该号已开 on-demand 并产生了真实账单。

登录设备

设备列表用登录票走接口。对应 dashboard Settings → Active Sessions。踢下线与官网 Revoke 相同，成功后应立刻从列表消失。接口不提供电脑名或 IP；若该号正在本机 Cursor 登录，一条客户端会标「本机」，多条则标「可能是本机」。
