领取规则（按套餐区分）

  • Pro / Pro+ / Ultra 账号：套餐自带 Sand 资格（Cursor 资格接口返回「付费套餐自动授予」），所以刚导入、一验证就显示「已开通 · 套餐自带」——这不是领取动作，验证是只读的。「领取」对这类号只是再确认一次，会提示「本来就已开通」。
  • Team 账号：走团队通道，「领取」会自动带 teamId 申请开通。

常用操作

  • 导入账号：粘贴 access_token / ws token / 邮箱----token（每行一个），或「导入文件」选 cursor_accounts_*.json。导入后自动验证：识别邮箱、套餐、订阅剩余时间、三池用量。账号与状态都会自动保存，下次打开无需重导。
  • 验证账号：只做检查，不领取（不会碰任何领取接口）。判定 token 是否有效（过期 / 被服务端拒绝会标「失效」），读取 Sand 资格状态、套餐、订阅剩余、三池用量。「Sand 状态」列的「已开通」来自 Cursor 的资格接口，下面小字会写「套餐自带」或「本次领取」。
  • 批量操作：验证 / 领取 / 删除 / 保护都只处理勾选的账号，未勾选时按钮不可点。顶部「更多」里还有清空全部。
  • 删除选中：删除勾选的账号；「清空全部」删列表里所有号（需确认个数）。
  • 探测 Refresh / 刷新登录票：从本机 Cursor 或号池整行记录 refresh_token；「刷登录票」向官方 OAuth 换新票，不踢设备。「刷票并踢旧」必须先换票成功，再立刻踢掉本工具原来那条客户端（官方换票会新开一台 Desktop App）；不会踢 Cursor IDE。切号默认先换新票再写入本机 Cursor，这样「本机」会落在最新那台设备上；取消勾选「先刷新登录票」则只切列表里当前这张票。
  • 显示 Token：点「账号列表」标题右侧的按钮，或某一行「登录信息」菜单里的「显示 Token」。会分别展示 Worksession（user_id::jwt）和 Refresh，可单独复制。默认关闭。
  • 进控制台：用该账号登录态打开隔离浏览器到 Cursor 控制台（dashboard/spending），可直接看用量 / 账单 / 设置。每个账号一个独立浏览器 profile，不影响你日常浏览器的登录。
  • 查看设备：用该号已有的登录票（token）直接调官方接口，不必每次浏览器登录。对应 dashboard Settings → Active Sessions；可勾选后踢掉所选，也可单台踢下线（与官网 Revoke 相同，成功后应立刻从列表消失）。刷登录票新开的 Desktop App 会标刚换票，并排到本机 / 本工具后面、比其它设备靠前（官方接口通常把它放在列表末尾）。若被网站人机校验拦截，点一次「打开 / 显示浏览器」即可：每个账号只开一扇隔离窗口，之后检测和踢下线都复用它，不会每 30 秒再开新窗口。请保持 cursor.com 标签不要关。接口不提供电脑名或 IP。若该号正在本机 Cursor 登录，会用本机 JWT 的签发时间去对客户端创建时间：对上恰好一条就标本机（共号多台客户端时也能认），并记住这台机器的机器码与 sessionId；对不上才退回「一条客户端=本机 / 多条=可能是本机」。切号重置机器码后需重新对上一次。
  • 本机设备保护：账号列表每行点「本机保护」打开本机保护页；一键本机保护在该页里，须先在本机 Cursor 登录该号。保护运行中也是打开该页，停止保护在该页里。开启前勾选要保留的设备，可用「全选保留 / 全不选 / 只留本机」，再点立即删除未勾选马上踢掉其余设备；也可设置检测间隔（秒，默认 30）后启动持续保护。该页里的「检测登录时间」会再弹一层设间隔（默认 120 秒）：把设备创建时间与本机现在比对，落在间隔内的标刚登录，并清空原勾选、只勾这些刚登录设备。一键本机保护用本机 Cursor 登录票的签发时间对上那条客户端，必要时连同本工具自己的会话一起保留，不会再靠刷登录票认设备。刷票会另开一条客户端，旧逻辑会把它当成「本机」把 Cursor 踢掉。对不上唯一一条 Cursor 客户端则不开保护。可同时保护多个账号：表格勾选后点「更多 → 批量保护」，每个号自动保留当前在线设备（有上次勾选则沿用），之后新登录会被踢；「停止选中保护」停勾选的号。顶部「保护中 N 个账号」可打开该页，多号时页里可切换。点「返回列表」或切到别的页只离开本页，不会停止保护。保留名单不能为空；踢掉本工具自己用的那张登录票后，保护最多约 10 分钟失效并自动停止。重启本工具后需要重新点「本机保护」或再批量开启（会回填上次的勾选与间隔）。
  • 云端 Agent：在顶部「云端 Agent」页。与登录票账号列表独立。把 Cursor Dashboard → API Keys 里创建的用户密钥（crsr_...）粘贴进来，按密钥列出该账号下全部 Cloud Agent（含已归档）。列表每行可单独删除；「一键清理」会永久删除这把密钥下的全部 Agent，不可恢复，删除前会弹出数量确认。密钥只存本机、不上传；列表不显示完整密钥，输入框会记住上次粘贴的内容。

额度怎么看

  • Bot 周用量：Sand（Grok Bot）专属额度，每周重置；来自 GetSandUsageStatus。
  • Auto 月用量 / 高级(API) 月用量：账单月内两个独立的池子，来自 usage-summary。三者互不相加；Cursor 自己的「总用量」是两池加权混合值，这里不再当用量显示。
  • 按量付费：若出现「已扣 $x」，说明该号已开 on-demand 并产生了真实账单。

登录设备

对应 Settings → Active Sessions。刷票新开的客户端会标「刚换票」并排到前面。勾选后可「踢掉所选」，成功后应立刻从列表消失。接口不提供电脑名或 IP。

检测登录时间

把每台设备的创建时间与本机现在比对。落在间隔内的会标「刚登录」，并清空原勾选、只勾这些刚登录设备（接口没有电脑名）。
